# 🛒 My E-commerce Website

## Overview
This is a modern **E-commerce web application** built with **React**, **Node.js**, and **MongoDB**.  
It allows users to browse products, add them to the cart, and make purchases online. The project demonstrates a full-stack development approach with a responsive UI and secure backend.

---

## Features
- **User Authentication** (Signup/Login)  
- **Product Browsing** with categories and search  
- **Add to Cart & Checkout** functionality  
- **Admin Panel** to manage products (optional if implemented)  
- **MongoDB** database to store products, users, and orders  
- **Secure API Endpoints** using Node.js and Express  

---

## Tech Stack
- **Frontend:** React.js, HTML, CSS, JavaScript  
- **Backend:** Node.js, Express.js  
- **Database:** MongoDB  
- **Other:** JWT (for authentication), Axios (for API calls)  

---

## Project Structure
/client # React frontend
/server # Node.js backend

/routes # API routes
